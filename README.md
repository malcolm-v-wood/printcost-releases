# PrintCost — downloads

A Windows app that works out what a 3D print really costs (filament, electricity, machine wear, labor, failure buffer) from Bambu Studio sliced files, and turns it into PDF invoices with profit reports.

**[Download the latest version](https://github.com/malcolm-v-wood/printcost-releases/releases/latest)** and pick `PrintCost-<version>.msi`. It installs like any Windows program and includes everything it needs, so there's no Java to install. Windows 10/11, 64-bit.

The installer isn't code-signed yet, so Windows may say "Windows protected your PC". Click **More info → Run anyway**.

From version 1.3.0 on, PrintCost tells you when a new version is out and can download and install it for you (Settings → Updates).
